# Пункты меню без backend (по референсу Sunrise, 2026-08-20)

Список пунктов, добавленных во frontend MMWS по референсному менеджеру
другого завода (`sunrise.pdf`, 9 скриншотов интерфейса) — по решению
пользователя добавлены ВСЕ пункты меню, которые видны на скриншотах,
даже там, где у MMWS ещё нет соответствующего backend. Такие пункты
отмечены в интерфейсе тегом «нет backend» и ведут на страницу-заглушку
(`frontend/src/pages/ComingSoonPage.tsx`). Конфигурация меню —
`frontend/src/constants/menu.ts`.

Список ниже — рабочий материал для обсуждения: по каждому пункту нужно
решить, реализовывать ли его в MMWS, в каком виде, и если пункт
пересекается с уже существующей функциональностью — объединять их или
оставлять раздельно.

## Архив

- Энергосеть (иерархия)
- Абоненты
- SIM-карты
- Точки учёта (POC)
- **Концентраторы (DCU)** ⚠️ пересекается с разделом Gateway (MMWS) — DCU
  у референса и Gateway у MMWS оба играют роль концентратора/шлюза
  между счётчиками и центральной системой. Решить: отдельная сущность
  или переиспользовать Gateway.

## Обслуживание

- **Работа со счётчиком (общая)** ⚠️ пересекается с карточкой счётчика
  MMWS (`/meters/:id`) — там уже есть чтение/запись параметров.
  Решить: нужен ли отдельный «общий» экран или это дубль.
- Опрос по GPRS
- Опрос DCU
- Опрос по PLC/RS485
- **Задачи параметров (Param Task Setting)** ⚠️ пересекается с разделом
  «Расписания опроса» MMWS (`/scheduled-jobs`) — концептуально близко,
  но не идентично (в референсе это скорее очередь/статус задач по
  конкретным счётчикам, а не расписание автоопроса).
- Обновление прошивки
- Анализ сети счётчиков (на скриншоте пункт был обрезан, возможно это
  два разных пункта — уточнить при живом просмотре референса)
- Результат настройки тарифа
